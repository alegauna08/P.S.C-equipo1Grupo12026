## Analisis  Computacional
Antes de empezar a programar pensamos que necesitabamos para poder hacer la pagina web
Primeroo analizamos que queriamos que hiciera
la aplicacion y despues pensamos que tecnologia ibamos a utilizar y nos decidimos.

## Que necesitamos?
Para hacer la pagina necesitamos:
- React para crear la pagina.
- Java Script para el funcionamiento.
- Html para la estructura.
- Css para el diseño web.
- Vercel para desplegar la pagina web a internet.
- Git y Git hub para guardar nuestro proyecto. 


## Que queremos que haga?
Queremos una nuestra pagina:

- Muestre los 118 elementos
- Los muestre ordenado
- Permita selecionar un elemento
