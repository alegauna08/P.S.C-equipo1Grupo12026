#  Memoria descriptiva

Este proyecto es una tabla periódica dinámica hecha con React para la escuela.

La idea fue hacerlo más simple, donde puedas hacer clic en cada elemento y ver su informacion.

Se desarrolló con React, HTML, CSS y JavaScript. 


#  Estudio de mercado


Hay varias tablas periódicas online pero la mayoría son complicadas o poco prácticas.

Este proyecto lo queremos hacer mas simple pensado para la escuela y para entender los elementos más fácil.

#  Story Telling

Un compañero tiró la idea de hacer una tabla periódica interactiva.

Vimos que las que hay online son medio complicadas o poco prácticas, así que decidimos hacerlo más simple y pensado para la escuela, para entender los elementos más fácil.
