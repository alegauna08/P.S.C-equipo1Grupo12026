# Registro de avances

## Nuestro avance

Durante el desarrollo de nuestro proyecto fuimos pasando por diferentes etapas.

### 1. Idea del proyecto

Primero decidimos realizar una **Tabla Periódica Dinámica** como aplicación web.

### 2. Diseño

Después pensamos cómo queríamos mostrar los elementos y cómo iba a ser la interfaz.

Queríamos que la tabla fuera fácil de entender y que los elementos pudieran seleccionarse.

### 3. Creación del proyecto

Creamos el proyecto utilizando React y Vite.

### 4. Incorporación de los elementos

Agregamos los datos de los 118 elementos químicos.

### 5. Organización de la tabla

Ordenamos los elementos para que representaran la distribución de una tabla periódica real.

### 6. Componentes

Dividimos la aplicación en diferentes componentes para poder organizar mejor el código.

### 7. Interactividad

Agregamos la posibilidad de seleccionar un elemento y mostrar información sobre él.

### 8. Diseño

Agregamos CSS para mejorar la apariencia de la página y organizar correctamente los elementos.

### 9. Pruebas

Probamos la página para comprobar que los elementos funcionaran correctamente.

### 10. Correcciones

Fuimos corrigiendo los errores que encontramos durante las pruebas.

### 11. GitHub

Subimos y organizamos el proyecto en GitHub.

También revisamos la actividad de los integrantes.

### 12. Despliegue

Preparamos la página para poder publicarla online mediante Vercel.

### 13. Documentación

Organizamos la documentación necesaria para el Hito 3.

### 14. Backups

También preparamos tres copias de seguridad del proyecto.

## Estado actual

Actualmente estamos revisando que todo esté funcionando, que los repositorios estén completos, que la documentación esté ordenada y que la página esté correctamente desplegada.
