## Cómo nos organizamos

Para realizar el proyecto nos dividimos las tareas entre los integrantes del grupo.

Cada uno fue trabajando en diferentes partes del proyecto, pero también fuimos ayudándonos entre nosotros cuando aparecían errores o había que realizar cambios.

Durante el desarrollo utilizamos:

- Visual Studio Code para programar.
- React para desarrollar la interfaz.
- Vite para crear y ejecutar el proyecto.
- JavaScript para la funcionalidad.
- HTML para la estructura.
- CSS para los estilos.
- Git para controlar los cambios.

- Vercel para publicar la página.
