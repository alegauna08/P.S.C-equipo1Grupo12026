# Guía de despliegue

## 1. Preparar el proyecto

Antes de publicar nuestra página verificamos que funcione correctamente de manera local.

## 2. Instalar las dependencias

Desde la carpeta `Main` ejecutamos:

```bash
npm install
```
## 3. Ejecutar el proyecto
Para iniciar la página utilizamos:

```bash
npm run dev
```
## 4. Subir el proyecto a GitHub

Una vez que comprobamos que funciona, subimos el proyecto a nuestro repositorio de GitHub.

También verificamos que los integrantes tengan actividad en el repositorio.

## 5. Conectar GitHub con Vercel

Ingresamos a Vercel y seleccionamos nuestro repositorio.

Vercel reconoce nuestro proyecto realizado con Vite.

## 6. Publicar

Realizamos el deploy desde Vercel.

Después de terminar obtenemos una URL pública.

## 7. Comprobar la página

Una vez publicada revisamos:

Que la página cargue.
Que aparezcan los elementos.
Que podamos seleccionar elementos.
Que aparezca la información.
Que los botones funcionen.
Que no haya errores visibles.
