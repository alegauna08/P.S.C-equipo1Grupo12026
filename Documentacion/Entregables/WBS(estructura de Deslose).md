# WBS (Estructura de Desglose deTrabajo) del Proyecto “Tabla Periódica”

## Introducción:

Este proyecto se trata de una Tabla Periódica Interactiva Web, hecha en React.js

## Declaración de Alcance (Scope Statement)

* **Objetivo Principal:** Desarrollar una aplicación web interactiva, moderna y responsiva de la Tabla Periódica, orientada a estudiantes y entusiastas de la química.
* **Criterios de Éxito:**
  * **Interfaz web fluida que cargue en menos de 5 segundos.**
  * **Filtros funcionales por grupos, períodos y bloques sin recarga de página (Single Page Application).**
  * **Fichas de información completas para los 118 elementos químicos.**
  * **100% de accesibilidad web básica (cumplimiento WCAG).**
* **Exclusiones (Fuera de alcance):**
  * **No se desarrollarán aplicaciones nativas (iOS/Android).**
  * **No incluirá un sistema de usuarios ni bases de datos con perfiles o historial de búsqueda.**
  * **No se ofrecerá modelado de moléculas en 3D avanzado, ni visualización de órbitas atómicas estáticas o animaciones CSS simples.**

## Identificación de Entregables Principales



* **Repositorio de código y arquitectura de desarrollo.**
* **Diseño de interfaz de usuario (UI) y prototipos navegables.**
* **Base de datos o archivo estructurado de datos (JSON/API) con la información química.**
* **Módulos de código frontend (Buscador, Tabla, Fichas, Filtros)**
