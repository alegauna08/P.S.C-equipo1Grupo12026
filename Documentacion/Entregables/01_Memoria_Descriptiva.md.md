# Memoria Descriptiva

## 1. Nombre de nuestro proyecto

**Tabla Periódica Dinámica**

## 2. ¿En qué consiste nuestro proyecto?

Nuestro proyecto consiste en una página web interactiva que representa la tabla periódica de los elementos químicos.

En la página podemos visualizar los 118 elementos y seleccionar cada uno para consultar información sobre él.

## 3. ¿Por qué hicimos este proyecto?

Elegimos realizar este proyecto porque queríamos transformar una tabla periódica tradicional en algo más interactivo.

Una tabla tradicional muestra mucha información de forma estática. Nosotros buscamos que el usuario pueda interactuar con los elementos y consultar la información de una forma más sencilla.

## 4. Objetivo general

Nuestro objetivo es desarrollar una página web que permita consultar los elementos químicos de una manera sencilla, visual e interactiva.

## 5. Objetivos específicos

Con nuestro proyecto buscamos:

- Mostrar los 118 elementos químicos.
- Ordenarlos correctamente.
- Permitir seleccionar cada elemento.
- Mostrar información del elemento seleccionado.
- Crear una interfaz sencilla.
- Hacer que la página sea fácil de utilizar.
- Publicar nuestra página online.

## 6. ¿A quién está dirigida?

Nuestra página está principalmente pensada para estudiantes y personas que necesiten consultar información básica sobre los elementos químicos.

## 7. Tecnologías utilizadas

Para desarrollar la página utilizamos:

- React.
- Vite.
- JavaScript.
- HTML.
- CSS.
- Git.
- GitHub.
- Vercel.

## 8. Cómo funciona

Cuando entramos a la página podemos observar la tabla periódica.

Cada elemento está representado dentro de la tabla.

Cuando seleccionamos uno, la página muestra información relacionada con ese elemento.

## 9. Resultado

Como resultado obtuvimos una página web interactiva que permite visualizar y consultar los elementos de la tabla periódica.

## 10. Conclusión

Con este proyecto pudimos aplicar conocimientos de programación web y aprender más sobre React, componentes, JavaScript, CSS, GitHub y despliegue.

También aprendimos a trabajar de manera organizada y a dividir las tareas entre los integrantes del grupo.
